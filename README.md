Iodium

A Fabric mod focused on performance, FPS stability, and reducing stuttering in Minecraft.

Supported Minecraft Versions

- Minecraft 1.21.11 — see the ""mc-1.21.11"" (https://github.com/BananaPixel-AFK/Mods-Iodium-/tree/mc-1.21.11) branch.
- Minecraft 26.1 — see the ""mc-26.1"" (https://github.com/BananaPixel-AFK/Mods-Iodium-/tree/mc-26.1) branch.
